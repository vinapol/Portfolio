# Portfolio — Moïse Techer

Site vitrine front-end (dark mode, Bento Grid, WCAG AA) pour présenter les projets de formation et personnels.

## Stack

Vite · React 19 · JavaScript · SCSS · Lucide

## Scripts

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
npm run lint
```

## Contenu

Les textes vivent uniquement dans `src/data/` (`profile.js`, `projects.js`, `skills.js`, `timeline.js`). L'UI ne contient pas de copie métier.
